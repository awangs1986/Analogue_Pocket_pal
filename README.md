# SDLPAL for Analogue Pocket

Publication in progress: the Pocket platform, FPGA display-mode RTL patch, tests and build driver are now in [source/pocket](source/pocket). The complete engine and pinned dependency inputs are being added in the next source-import commit. This checkpoint is not a complete build checkout.

No new Quartus bitstream or physical Pocket/Dock acceptance is claimed. Ogg/Vorbis is decoded on the RISC-V CPU; the FPGA outputs PCM. No proprietary PAL game assets are included.
