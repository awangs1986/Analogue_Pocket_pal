# SDLPAL for Analogue Pocket

Source publication is being assembled from the verified 2026-10-05 build handoff.

This is an unvalidated development port, not a hardware-ready release. The game engine runs on a RISC-V CPU; Ogg/Vorbis is CPU-decoded and the FPGA outputs PCM. The new display-mode RTL has not completed Quartus synthesis/timing closure or physical Pocket testing.

No proprietary game assets are included. Engine baseline: https://github.com/awangs1986/mister_pal/tree/1d35d896b99722b9968685c1284cb5f1566cd662 . Full licenses, source, build specifications, and provenance will follow in the source-import commit.
